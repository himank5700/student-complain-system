How It Works

Designed for Students and College Staff

A streamlined 4-step workflow from problem identification to verified resolution.

1. Secure Login

Students and administrators log in with role-based JWT authentication and encrypted credentials.

2. Lodge Complaint

Select your college facility category, input grievance details, and instantly receive a tracking ID.

3. Track Progress

Watch real-time status transitions: Submitted, Under Review, In Progress, and Resolved.

4. Verified Resolution

Admins assign campus departments, provide official remarks, and resolve issues transparently.

Academic & DevOps Project

Enterprise Architecture Meets DevOps Practices

This project demonstrates a production-grade Software Delivery Lifecycle (SDLC) created for academic evaluation. It combines a robust Node.js and Express backend with MySQL database integrity, Docker containerization, and automated GitHub Actions CI/CD.

  • Frontend: Responsive HTML5, CSS3, JavaScript, Bootstrap 5
  • Backend: Node.js, Express.js, JWT Auth, Bcrypt hashing
  • Database: MySQL 8.0 relational schema with parameterized queries
  • DevOps: Docker, Docker Compose, Nginx Reverse Proxy, GitHub Actions
